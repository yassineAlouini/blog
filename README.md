# The Notebook Blog

High-scoring Kaggle notebooks and research write-ups by
[Yassine Alouini](https://www.kaggle.com/yassinealouini/code) — computer vision,
multi-modal applications and LLMs — ported to standalone, shareable HTML in a
quiet, *old-web* reading layout: serif text on white, navy headings and links,
thin rules, and muted ochre tags.

**Live site → https://yassinealouini.github.io/blog/**

## What's on the blog

The landing page (`index.html`) is organized into themed sections. Each post is a
self-contained HTML page under `posts/` with the original narrative, math and code.
Each section has a small pixel-art GIF: a segmentation scan for Computer Vision,
a moving filmstrip for Video Processing, flowing tokens for NLP & LLMs, and a
random weight matrix feeding a neural network above a moving spectrum for Research. They share the navy and ochre
palette. A single control pauses all four; reduced-motion preferences select
static images even without JavaScript.

The Research animation is a tiny “signal emerging from noise” experiment: a fixed,
seeded 12×12 Gaussian weight matrix gains and loses a rank-one component. The
blue histogram shows the remaining eigenvalues of WᵀW; a gold marker follows the
largest eigenvalue as it separates from the bulk. Gold pulses cross a schematic
network above it. The spectrum is computed from the toy matrix on every exported
frame; the network and changing signal are illustrations, not a trained model or
a claimed asymptotic law. The loop and its PNG still are exported by the same
renderer as the other section icons.

## How it's built

`build.py` is a small static-site generator (no framework). It builds two kinds of post:

- **Notebook posts** (`POSTS`) — one Kaggle notebook each, from `_src/<slug>/<slug>.ipynb`.
- **Markdown posts** (`MD_POSTS`) — hand-written articles from `_static/<slug>.md`
  (e.g. the LeCun world-models digest).

Both go through the same renderer and page shell:

- **markdown** via [mistune](https://github.com/lepture/mistune) — including `$…$` math
  (handed to **MathJax**), tables, and notebook image attachments inlined as data URIs;
- **code** (notebook cells *and* fenced blocks inside markdown) via
  [Pygments](https://pygments.org/) syntax highlighting;
- wrapped in a branded page shell and shared CSS.

It then generates `index.html`, grouping posts into sections by their `category`. A post's
`category` may be a **string or a list**, so a post can appear in several sections.
Empty sections are skipped.
Styling lives in `assets/style.css` (an old-web theme: system serif fonts, navy
rules and square boxes, underlined links, and muted ochre tags) and
`assets/pygments.css` (Pygments' black-and-white `bw` style, regenerated by `build.py`).

### Repository layout

```
build.py              # the generator
index.html            # generated landing page (sections + cards)
posts/                # generated post pages (one .html per post)
assets/
  style.css           # navy and ochre old-web theme (shared)
  pygments.css        # black-and-white code highlighting (generated)
  sections/           # four 96×64 GIFs and matching PNG stills
  section-animations.js # pause, reduced-motion, and visibility controls
code/render-section-gifs.py # optional exporter (Pillow + Playwright Chromium)
code/section-gif-renderer.js # deterministic pixel-art source
_src/<slug>/<slug>.ipynb   # source notebooks pulled from Kaggle (notebook posts)
_static/<slug>.md          # hand-written markdown articles (markdown posts)
```

### Rebuild

```bash
python3 build.py        # regenerates posts/ and index.html
```

Dependencies: `mistune`, `pygments` (MathJax loads from a CDN at view time; fonts are the
reader's own system fonts).

### Add a new post

**From a Kaggle notebook:**
1. Pull it into `_src/<slug>/<slug>.ipynb`
   (`kaggle kernels pull yassinealouini/<slug> -p _src/<slug>`).
2. Add an entry to the `POSTS` list in `build.py` with `slug`, `title`, `subtitle`,
   `tags`, and `category`.

**As a hand-written article:**
1. Write `_static/<slug>.md`.
2. Add an entry to the `MD_POSTS` list in `build.py` (same fields, plus `src` pointing
   at the markdown file and an optional `source` link).

`category` is one of `"Computer Vision"`, `"Video Processing"`, `"NLP & LLMs"`, `"Research"`, …
(or a **list** of them to cross-list). New sections appear automatically; empty ones are skipped.
Then run `python3 build.py` and commit & push.

## Deployment

Served by **GitHub Pages** from the `master` branch root. Pushing to `master`
triggers a rebuild; the live site updates within a minute.

> Code snippets are faithful reconstructions of the Kaggle notebook sources (narrative + code);
> cell outputs are not re-executed here — run a notebook on Kaggle for live results.

Website generated with assistance from AI agents. The look is shared with
[Light to Dark](https://github.com/yassineAlouini/watercolor-helper): an old-web page, kept
elegant and minimal.

The top navigation is styled by `/assets/site-navigation.css`, served by the
personal homepage repository. That single file keeps the homepage, Sketchbook,
blog index and posts visually consistent. `site_navigation()` in `build.py`
uses the same Home / Blog / Sketchbook / GitHub order as the personal site.
For a local preview including that stylesheet and those destinations, run
`python3 code/serve.py` from the adjacent `yassineAlouini.github.io` repository.

The “Get the book” link uses the same open-book SVG, wording, destination and
plain-link styling as the personal homepage. Keep `.book-link` / `.book-icon`
styles and the SVG in `build.py` aligned with that repository.
